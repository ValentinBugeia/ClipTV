Twitch highlights, ready for TikTok

ClipTV is a personal desktop tool for content creators. It finds popular moments from Twitch streams, turns them into vertical videos with subtitles, and publishes them to the creator's own TikTok account, after the creator has reviewed each video.

How it works

  1. Find — ClipTV lists popular public clips from Twitch (Twitch API).
  2. Edit — each clip is converted to the 9:16 vertical format, the streamer's face is framed and animated subtitles are added. A caption credits the streamer (twitch.tv/<channel>).
  3. Review — the creator watches the video, edits the caption, and chooses the TikTok settings (who can view the video, comments, duet, stitch, content disclosure).
  4. Publish — with the creator's confirmation, ClipTV publishes the video to the creator's TikTok account through the official TikTok Content Posting API, now or at a time the creator picked.

TikTok integration

ClipTV uses Login Kit so the creator can connect their own TikTok account, and the Content Posting API to publish the videos they approved. With the creator's permission, it also reads the public statistics of their videos (views, likes, comments, shares) to show which videos perform best. ClipTV only acts on the account of the creator who connected it.

Where ClipTV runs

ClipTV is installed and runs on the creator's own computer. There is no ClipTV server and no ClipTV account: videos, captions and TikTok access tokens stay on that computer. See the Privacy Policy.
